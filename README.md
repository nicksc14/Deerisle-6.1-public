# HEROCLAN 鹿岛｜DeerIsle 6.1

HEROCLAN 鹿岛是基于 DayZ DeerIsle 地图打造的服务器项目。玩家从搜集物资、完成任务和熟悉岛屿开始，逐步探索跑刀区域、挑战不同难度的副本，并通过交易、合成和装备积累规划自己的生存路线。

这个仓库保存经过隐私清理的服务器配置快照，方便查看和参考。玩法与配置会随项目调整，实际服务器内容以当前部署版本和游戏内表现为准。

## 在鹿岛做什么

- **探索与生存**：在城镇、野外和各类地点搜寻补给，管理装备、医疗用品与返程物资。
- **任务与成长**：通过 NPC 任务、日常和周常寻找目标，获得资源并逐步熟悉岛上的活动。
- **五岛跑刀**：以较轻的装备进入区域，寻找补给和钥匙，权衡继续探索与安全撤离。
- **分级副本与 AI**：根据自己的装备与经验选择挑战，面对不同区域的 AI 和更高风险的战斗，寻找对应的战利品。
- **合成与经济**：收集材料，使用工作台制作装备和物资；通过商人、市场及黑市进行交易，为下一次行动做准备。
- **休闲与长期目标**：钓鱼、狩猎、收藏、基地建设和比特币矿机，为不同行动方式提供其他成长方向。

独自行动可以先从熟悉路线和积累补给开始；小队则可以在战斗、警戒、医疗和运输之间分工。挑战的具体规则、奖励和开放情况以服务器当前设置为准。

## 仓库内容

```text
profiles/                    模组及服务器配置快照
  ExpansionMod/              Expansion 任务、市场、AI 等配置
  BS_KeyRoom/                跑刀房间与门的配置
  CJ_LootChests/             奖励箱及其物资配置
  Hunter_Mods/               Hunter Mods 相关配置
  TerjeSettings/             Terje 相关设置
mpmissions/
  empty.deerisle/            DeerIsle 任务目录、中央经济及地图配置
```

`profiles` 中的文件通常对应服务器启动时指定的 `-profiles` 目录；`mpmissions/empty.deerisle` 是任务目录。实际加载位置、模组版本与启动参数取决于服务器实例的设置。

## 管理与使用

- 本仓库是配置快照，并非完整的服务器安装包；DayZ 服务端、地图及所需模组、PBO、密钥和启动配置需要另行准备。
- 部署前应核对目标实例、模组版本、加载顺序、任务目录与 `-profiles` 路径，并备份目标配置。部分配置可能依赖与其匹配的自定义模组版本。
- 修改配置后，应按改动范围检查语法和引用，再结合服务器启动日志与游戏内测试确认加载和玩法表现。仓库中的文件存在不等于已经部署或验证。
- 公开版本已清除管理员及玩家身份、封禁记录、许可文件和服务器社区邀请等信息；`profiles/VPPAdminTools/Permissions/credentials.txt` 与 macOS 的 `.DS_Store` 文件也未包含。请勿直接用公开快照覆盖运行服务器的管理员、封禁和许可配置；必要信息应从安全位置单独管理。

> 本仓库记录的是上传时的本地文件快照，后续本地修改不会自动同步。
