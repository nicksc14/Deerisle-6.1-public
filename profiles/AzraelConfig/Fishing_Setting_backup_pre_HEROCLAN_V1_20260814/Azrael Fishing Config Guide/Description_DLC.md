# Azrael Fishing Mod
# DLC Real Fisher
## DESCRIPTION

## RU: 
Real Fisher - дополнительное расширение

## Основные возможности:
- Шанс появления рыбы и частота клёва в зависимости от времени суток.
- Детальная настройка каждого часа в сутках.
- Глубина обитания рыбы: крупную рыбу больше нельзя просто так поймать у самого побережья.
- Книга-справочник, содержащая информацию о времени активности рыбы, глубине обитания, требуемых снастях и других данных, которые автоматически загружаются из ваших конфигов.




## EN:
Real Fisher - additional expansion

## Main features:
- Fish spawn chance and bite frequency depending on the time of day.  
- Detailed configuration for every hour of the day.  
- Fish habitat depth: large fish can no longer be easily caught right near the shore.  
- A reference book containing information about fish activity time, habitat depth, required equipment and other data, automatically loaded from your config files.
