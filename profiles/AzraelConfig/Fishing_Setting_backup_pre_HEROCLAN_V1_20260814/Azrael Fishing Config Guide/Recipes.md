# Azrael Fishing Mod
# RECIPES

### RU: 
Хлебная приманка = сухарь + любой нож
Сырная приманка = сыр + любой нож
Кукурузная приманка = кукуруза + любой нож
Мясная приманка = любое мясо + любой нож

Примитивная удочка и леска = длинная палка + веревка
Примитивная леска = веревка + любой нож
Части примитивной катушки = доска/дрова 1 шт. + любой нож
Примитивная катушка = части примитивной катушки 3 шт. + веревка
Крючок из консервной банки = пустая банка от газировки + любой нож

### EN: 
Bread bait = breadcrumb + any knife
Cheese bait = cheese + any knife
Corn bait = corn + any knife
Meat bait = any meat + any knife

Primitive fishing rod and line = long stick + rope
Primitive fishing line = rope + any knife
Parts of a primitive reel = 1 piece of wood/wood + any knife
Primitive reel = 3 parts of a primitive reel + rope
Tin can hook = empty soda can + any knife
