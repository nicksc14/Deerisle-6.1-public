# Deer Isle 新手任务链地图设计

## 目标

从 `deerisle_map.png.xyz` 读取地图坐标系，将 Expansion Quest 新手任务链精确投影到 `deerisle_map.png` 上，输出一张简洁、清晰、可直接用于检查任务递进关系的地图。

成品只显示新手任务涉及的鹿岛南部地图区域，不在全图上标注无关位置。

## 已确认的方案

采用“单张主图 + Stonington 城区放大框”：

- 主图表达 `901–909` 的整体地理进程、进入 Stonington 的关系，以及城区阶段结束后的 `902→1211`。
- 放大框从 `910` 开始，表达 Stonington 内部的 `910–918` 依赖、串行和汇合关系。
- 不将任务依赖线伪装成道路导航；箭头只表示“解锁/前置关系”。
- 地图标签仅保留 Quest ID 和简短中文名称，不显示奖励、对话或配置字段。

## 坐标源与投影

`deerisle_map.png.xyz` 的结构为：

- 8 字节头部。
- `4096 × 4096` 个记录。
- 每条记录为 3 个 little-endian `float32`：世界 `X`、世界 `Z`、地形高度。
- 网格间距为 4 米，水平范围为 `0–16380`。

世界坐标到原图像素的换算为：

```text
pixel_x = world_x / 4
pixel_y = 4095 - world_z / 4
```

坐标系中的地形高度不参与平面投影。所有任务点先投影到 4096 像素原图，再统一应用裁切和缩放变换，避免标记偏移。

## 任务依赖

主链和分支必须按以下结构表达：

```text
901 → 904 → 905 → ┌→ 906 ─┐
                    └→ 907 ─┘ → 908 → 909 → 910

910 → 911
    → 912
    → 913 → 916 → 917
    → 914
    → 915

911–917 全部完成 → 918 → 902 → 1211
```

`902` 的当前 JSON 直接列出 `911–918` 为全部前置。由于 `918` 本身已要求 `911–917` 全部完成，成品将重复的八条入线折叠为 `918→902`，但在箭头旁注明“城区阶段全完成”。这是视觉简化，不是配置语义变更。

`914` 为收集任务，`915` 为制作任务，两者没有可以作为地理目标的固定位置。它们将以“非定点任务”节点放在城区放大框边缘，不伪造地图坐标。

## 画布与布局

- 输出为横向 PNG，建议画布约 `2560 × 1600` 像素；如果实际排版需要，可小幅调整但不得降低标签可读性。
- 主地图裁切范围以世界坐标 `X=5200–11000`、`Z=900–6500` 为基准，覆盖所有新手链定点并留出标签边距。
- 主图占据画布大部分；Stonington 放大框位于右侧，地理范围约为 `X=6000–7300`、`Z=1100–2550`。
- 主图中以一个清晰的范围框指示 Stonington 放大区域，并以单根引导线对应到放大框；主图不重复标出 `910–918` Quest ID。
- 放大框中显示 `910` 入口、`911–918` 任务和 `914/915` 非定点节点。从 `918` 通往主图 `902` 的引导线不在放大框重复显示 `902` ID。

## 视觉编码

- 背景地图适度压暗，保留道路、海岸、城镇和地形可辨识度。
- 任务点使用高对比圆形标记，标记内显示 Quest ID。
- 文字使用白色或近白色，放在深色半透明底板上；标签之间不允许相互覆盖。
- 只使用三个阶段色：`901–910` 前期阶段、`911–918` 城区阶段、`902–1211` 收尾阶段。
- 颜色不是唯一信息通道；每条关系同时通过 Quest ID、箭头方向、分支/汇合形状表达。
- `906/907` 并行后汇合到 `908`；`911–917` 通过明确的“全部完成”门节点汇合到 `918`。
- 图中包含小型北向标和 1 km 比例尺，不增加其他装饰元素。

## 产物

- 主产物：`其他本地项目/deerisle_novice_quest_chain_map.png`
- 原始 `deerisle_map.png` 和 `deerisle_map.png.xyz` 必须保持不变。
- 如制图过程产生可编辑的中间源文件，应放在独立目录中，不与 Expansion Quest 服务器配置混放。

## 验收标准

1. 成品只展示新手任务链涉及的地图区域。
2. `901、902、904–918、1211` 每个 Quest ID 都恰好出现一次于对应的主图或放大框节点中。
3. 依赖结构与当前 Quest JSON 一致，尤其是 `906/907` 并行汇合、`913→916→917` 串行、`911–917→918` 全完成门和 `918→902→1211`。
4. 位置标记由世界坐标经统一公式投影，与道路、城镇或目标地形相符。
5. `914/915` 明确标识为非定点任务，不使用伪造坐标。
6. 在原始分辨率查看时，所有 ID、简称、箭头、汇合门均清晰可读，无文字裁切和重大覆盖。
7. 缩小至约 50% 显示时，仍能看懂主链方向、两个关键汇合和三个阶段。
8. 原始 PNG 和 XYZ 文件的哈希在制图前后一致。
